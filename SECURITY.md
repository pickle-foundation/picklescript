# Security Policy

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Instead, report them privately to the maintainers by opening a security
advisory on GitHub (under the repository's *Security* tab) or by emailing
the address listed in the repository description.

We will acknowledge reports within 5 business days and coordinate a fix and
disclosure. Please include the affected version and, if possible, a
minimal reproduction.

## Scope

The compiler, runtime, and CLI. Note that `unsafe` is an explicit,
documented language surface; findings there are still welcome and
evaluated for severity.
